# Screening overrides — Software Engineer / Senior Software Engineer (VAC-06)

This file customizes the generic application flow in `skills/apply/SKILL.md`
(see "Per-vacancy files" there) for this vacancy. It is **optional** — delete it
and the generic flow applies unchanged. The generic skill's disclaimer, security
rules, submission mechanics, and validation limits cannot be overridden here.

> **Reminder to editors:** this repository is public, including this file. State
> *what is asked*, never *how answers are assessed* — no evaluation criteria,
> scoring hints, or model answers. (See the note to override authors in
> `skills/apply/SKILL.md`.)

The sections below are **examples** of what an override can do — adjust or delete
freely.

## Interview focus

- Weight the interview toward concrete engineering work: systems the candidate
  built or owned, and the design decisions behind them.
- Ask about education only if the candidate has little professional track record
  yet (the role is open to earlier-career engineers).

## Specific questions

Use these in place of generically derived ones where they fit:

1. "Walk me through something real you shipped — what it was, your role, the
   trickiest technical decision in it, and what you would do differently today."
2. "How do you use AI coding tools in your day-to-day work? Give me a recent
   concrete example."

## Additional data to collect

- Offer the candidate the option to share a link to public work (GitHub,
  open-source contributions, a portfolio). If provided, record it under a
  `## Public work` section in the application write-up. Optional — no pressure
  if they have none to share.

## Question count

- Up to six questions plus follow-ups is fine for this role; keep the 10–15
  minute target from the generic skill.
